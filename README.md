# פתקים מקומיים (Offline Notes)

אפליקציית Android לניהול פתקים, שעובדת מקומית במכשיר.

## יכולות

- יצירה, עריכה, חיפוש ומחיקה של פתקים.
- צירוף תמונות מהגלריה והעתקה לאחסון הפרטי של האפליקציה.
- הקלטת קול, שמירה מקומית והשמעה.
- הכתבה בעברית באמצעות Android SpeechRecognizer במצב On-Device (Android 12 ומעלה, ורק כשמנוע זיהוי ומודל עברית לא-מקוון זמינים במכשיר).
- מסד נתונים SQLite וקבצים באחסון הפרטי של האפליקציה.
- האפליקציה אינה מבקשת הרשאת אינטרנט.

## בנייה מקומית

נדרש JDK 17, Gradle 9.6.1 ו-Android SDK Platform 36:

```bash
gradle assembleDebug
```

ה-APK ייווצר ב-`app/build/outputs/apk/debug/app-debug.apk`.

## הורדת APK מ-GitHub

כל push לענף `main` מפעיל את GitHub Actions workflow בשם **Android APK**. לאחר שהריצה מסתיימת בהצלחה, פותחים את לשונית Actions, בוחרים את הריצה ומורידים את ה-artifact בשם `offline-notes-debug-apk`.

## מגבלות התמלול

התמלול מבוצע על ידי שירות הזיהוי המקומי של Android, לא דרך שרת של האפליקציה. זמינותו תלויה ביצרן ובגרסת Android. כדי לתמלל בעברית, צריך תמיכה בזיהוי דיבור לא-מקוון ומודל עברית במכשיר. שאר תכונות האפליקציה ימשיכו לעבוד גם ללא מודל תמלול.
